# Security policy

## Supported versions

Only the **latest release** of NINA receives fixes. Please update before reporting a problem.

## Reporting a vulnerability

If you find a security problem in NINA (for example a crash that can be triggered by a crafted
kit, sequence, song or audio file, or any way the program could be made to run unwanted code),
please **do not open a public issue**.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose
**Report a vulnerability**. Include the version of NINA, what you did and, if possible, the
file that triggers the problem.

This is a personal project maintained in spare time: I will answer as soon as I can, and I will
publish a fixed version before describing the problem in public.

## What NINA does and does not do

- NINA works offline. The only network access is the optional **Check for updates** button in the
  About window, which asks GitHub for the latest published version **only when you press it**.
- The **Support my work** button just opens a PayPal page in your web browser.
- NINA does not collect, store or send any personal data.
