# Sample Lab – Manuale d'uso

Sample Lab è un campionatore a celle (stile drum machine) con sequencer a step, disponibile come plugin **VST3** e come applicazione **standalone**. Questa raccolta spiega come usarlo, dal primo avvio all'esportazione nella DAW.

## Convenzioni

- Le note MIDI seguono la convenzione di Cubase: **C3 = 60** (quindi C1 = 36).
- *Cella*: uno dei 48 pad della griglia (4 righe A–D × 12 colonne). *Riga* (o *lane*): una cella aggiunta al sequencer. *Step*: un passo della riga.
- I nomi dei pulsanti sono scritti come appaiono nell'interfaccia (in inglese), per esempio **Normalize**, **Export lanes**.
