# NINA – User manual

NINA is a cell-based sampler (drum machine style) with a step sequencer, available as a **VST3** plug-in and as a **standalone** application. This collection explains how to use it, from the first launch to exporting into the DAW.

> Reference version: state of the project at the latest commit. Features that are not yet present or not yet verified are marked in each chapter and in the list of limits (chapter 8).

## Conventions

- MIDI notes follow the Cubase convention: **C3 = 60** (so C1 = 36).
- *Cell*: one of the 48 pads of the grid (4 rows A–D × 12 columns). *Row* (or *lane*): a cell added to the sequencer. *Step*: one step of a row.
- Button names are written as they appear in the interface (in English), for example **Normalize**, **Export lanes**.
